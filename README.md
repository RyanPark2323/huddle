# Huddle

An open-source sweep orchestrator for ad hoc, trust-based compute groups —
run a hyperparameter sweep across whatever friends' machines are online
tonight, with zero cloud account, zero admin rights, and zero shared
filesystem required.

**Status:** Paused in Early Development

## Quickstart (coming soon)

```bash
huddle coordinator start
uvx huddle agent join <tunnel-url> --token <token>
```
